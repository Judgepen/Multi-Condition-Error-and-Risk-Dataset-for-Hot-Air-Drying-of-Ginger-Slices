# 烘干过程建模数据（发布候选包）

本仓库候选包包含烘干过程建模所用的三个 Excel 工作簿。文件保留原始表格内容，未做清洗、删改或单位换算。

## 文件清单

| 文件 | 内容 |
|---|---|
| `data/附件1.xlsx` | 烘房边界时序，包含时间、温度和水分浓度列。 |
| `data/附件2.xlsx` | 几何/收缩相关时序，包含时间和半径列。 |
| `data/result1.xlsx` | 参考场结果，含“温度”和“水分浓度”工作表；首列为时间，后续列对应径向位置。 |

数据单位、变量定义及原始来源以对应竞赛题面和材料说明为准。使用者应先核对题面中的单位与符号约定。
